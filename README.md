# Portfolio site

A responsive, static portfolio site ready for GitHub Pages. No build step is required.

## Publish with GitHub Pages

1. Replace the sample name, email address, social links, and project links in `index.html`.
2. In the repository on GitHub, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site is served from `index.html`; styles are in `style.css`. Project artwork is made from CSS, so you can swap in your own images later if you prefer.
